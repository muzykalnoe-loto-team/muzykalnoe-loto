# Старые слайды в новых играх — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каждый третий бочонок новой игры (3, 6 … 90) — песня из старых игр оператора (фото + звук с исходной обрезкой), собранная на шаблоне «Рабочий 2 вар» в новом оформлении.

**Architecture:** Один раз старые презентации (`Исходники/Старый дизайн/`, 55 ГБ) разбираются без PowerPoint, на уровне zip: песня узнаётся по тексту слайда и сводам, каждый песенный слайд целиком (со звуком, обрезкой, затуханием, громкостью) сохраняется отдельным файлом `Банк старых слайдов/<Исполнитель - Название>.pptx`. Из видео-банка и банка старых слайдов собирается «Общий банк песен». Подбор ставит старые слайды на бочонки, кратные 3; сборка на «Рабочий 2 вар» вставляет фото в рамку шаблона (python-pptx), а название, исполнителя и звук с автозапуском — через PowerPoint COM.

**Tech Stack:** Python 3.13, zipfile + re (разбор .pptx без PowerPoint), openpyxl, python-pptx (+Pillow — для тестов), pywin32 (PowerPoint COM), pytest.

**Spec:** `Спецификация — старые слайды.md` (корень проекта). Общая архитектура — `Спецификация.md`, предыдущий план — `План реализации MVP.md`.

## Global Constraints

- Windows + Microsoft PowerPoint 16 через COM (`win32com.client.Dispatch`, не `EnsureDispatch` — битый кэш gen_py); PowerPoint закрывать только если `ppt_app.Presentations.Count == 0`.
- Запуск — `python` (не `python3`). Новых зависимостей не добавлять (python-pptx, openpyxl, pywin32, Pillow уже стоят).
- Пути — только из `scripts/paths.py`. Файлы `Исходники/`, `events/`, `.env` в git не попадают.
- `Исходники/Старый дизайн/` — только чтение, ничего не менять и не удалять.
- Песня в банках и списках — строка `"Исполнитель - Название"` (разделитель ` - `).
- В новой игре 90 бочонков; бочонки, кратные 3, — старые слайды (`kind: "old"`), остальные — видео (`kind: "video"`).
- Шаблон смешанной игры — `Исходники/Рабочий 2 вар.pptx`; игры только с видео — `Исходники/Рабочий 3 вар.pptx`.
- Слот бочонка: слайд 15 + номер (бочонок 1 → слайд 16, бочонок 90 → слайд 105). Слайд целиком не заменять; кнопка перехода на слайд 15 в слотах «Игровой слайд» — в макете, на слайд её не добавлять.
- Рамка фото в слоте: 46–914 × 34–506 pt; кнопка макета: 863–960 × 443–540 pt; угол слайда (точка 940, 520 pt) ничем на слайде не закрывать.
- Сжатие звука/картинок/видео не делать.
- Правила проекта (CLAUDE.md): одна задача за раз, после неё — запись в `отчёт.md`, коммит и `git push`, наглядный результат (Excel/картинки) со ссылкой, остановка и вопрос «идём дальше?».

## Review Focus

- Длинное название (правило оператора, 2026-10-08): название может занимать **до двух строк** в любом слоте; «Коламбия Пикчерз не представляет» встаёт в две строки без уменьшения. Если и в две не влезает — размер шрифта уменьшается, пока не влезет в две. Название в две строки в слоте «НА 1 СТРОЧКУ» раздвигает название и исполнителя поровну (как в заготовке «ТЕКСТ НА 2 СТРОЧКИ»), они не налезают друг на друга (тесты — Task 5).
- Песня без своего фото (на слайде только оформление) — рамка остаётся пустой, сборка не падает (тесты — Task 1 и Task 5).
- Название с символами, запрещёнными в именах файлов («5sta Family - Зачем?»), и две песни, дающие одно имя файла, — файлы не перезаписывают друг друга, каталог хранит точное имя файла (тест — Task 3).
- Одна песня записана в видео-банке и в своде по-разному («Королёва»/«Королева», лишние пробелы, запятые) — в общем банке это одна строка с обоими видами (тест — Task 4).
- Старый слайд стоит не на своём бочонке (кратном 3) или список старого формата без `kind` — понятная ошибка до запуска PowerPoint / список без `kind` собирается как раньше на «Рабочий 3 вар» (тесты — Task 6).

```python
import re

_FORBIDDEN = re.compile(r'[<>:"/\\|?*\x00-\x1f]')


def norm(text: str) -> str:
    """Ключ для сравнения песен: без регистра и пунктуации, ё = е."""
    return re.sub(r"[^0-9a-zа-я]", "", str(text).lower().replace("ё", "е"))


def split_raw(raw: str) -> tuple[str, str]:
    """«Исполнитель - Название» → (исполнитель, название). В базе бывает дефис без пробела."""
    if " - " in raw:
        artist, title = raw.split(" - ", 1)
    else:
        artist, _, title = raw.partition("-")
    return artist.strip(), title.strip()


def make_raw(artist: str, title: str) -> str:
    return f"{' '.join(str(artist).split())} - {' '.join(str(title).split())}"


def safe_filename(raw: str) -> str:
    """Имя файла Windows из названия песни: запрещённые символы → «_», без точек в конце."""
    return _FORBIDDEN.sub("_", raw).strip().rstrip(". ")[:150]
```

import io
import os

import openpyxl
from PIL import Image
from pptx import Presentation
from pptx.opc.package import Part
from pptx.opc.packuri import PackURI
from pptx.util import Pt

from scripts.old_slides import choose_best, identify_song, load_svod_songs, scan_presentation

def _png(color, size=(40, 30)):
    buf = io.BytesIO()
    Image.new("RGB", size, color).save(buf, "PNG")
    buf.seek(0)
    return buf


def _write_svod(folder, rows):
    os.makedirs(os.path.join(folder, "Тема"), exist_ok=True)
    wb = openpyxl.Workbook()
    wb.active.title = "СОДЕРЖАНИЕ"
    ws = wb.create_sheet("Игра")
    for i, (artist, title) in enumerate(rows, 1):
        ws.append([i, f"{artist} - {title}", artist + " ", title])
    wb.save(os.path.join(folder, "Тема", "Тема_СВОД песен.xlsx"))


def _make_old_game(path, slides):
    """slides: список (тексты, цвет_фото | None). На каждом слайде — звук и общая картинка оформления."""
    prs = Presentation()
    decor = _png((0, 0, 0), (10, 10)).getvalue()
    for texts, photo in slides:
        slide = prs.slides.add_slide(prs.slide_layouts[6])
        for i, t in enumerate(texts):
            slide.shapes.add_textbox(Pt(20), Pt(20 + 40 * i), Pt(300), Pt(30)).text_frame.text = t
        slide.shapes.add_picture(io.BytesIO(decor), Pt(0), Pt(0), Pt(10), Pt(10))
        if photo:
            slide.shapes.add_picture(_png(photo), Pt(50), Pt(50), Pt(400), Pt(300))
        # звук: связь с mp3 — этого достаточно, чтобы слайд считался песенным
        part = slide.part
        mp3 = Part(PackURI(f"/ppt/media/media{len(prs.slides)}.mp3"), "audio/mpeg", prs.part.package, b"ID3fake")
        part.relate_to(mp3, AUDIO_REL)
    prs.save(path)

```python
# Узнавание песенных слайдов в старых играх — без PowerPoint, чтением .pptx как zip
import glob
import html
import os
import posixpath
import re
import zipfile
from collections import Counter

import openpyxl

from scripts.song_names import make_raw, norm, split_raw

AUDIO_EXT = (".mp3", ".m4a", ".wav", ".wma", ".aac")
VIDEO_EXT = (".mp4", ".mov", ".wmv", ".avi", ".m4v")
IMAGE_EXT = (".png", ".jpg", ".jpeg", ".gif", ".bmp")
# Картинка, которая стоит на половине песенных слайдов игры и больше, — оформление, а не фото
DECOR_SHARE = 0.5
CHECK_UNKNOWN = "не узнана по своду — проверьте написание"
CHECK_AMBIGUOUS = "подходят несколько песен свода — проверьте"


def load_svod_songs(folder: str) -> list[dict]:
    songs = {}
    for path in sorted(glob.glob(os.path.join(folder, "*", "*СВОД*.xlsx"))):
        if os.path.basename(path).startswith("~$"):
            continue
        wb = openpyxl.load_workbook(path, read_only=True, data_only=True)
        for ws in wb.worksheets[1:]:  # первый лист — «СОДЕРЖАНИЕ»
            for row in ws.iter_rows(values_only=True):
                if not row or not isinstance(row[0], int) or not row[1]:
                    continue
                if len(row) > 3 and row[2] and row[3]:
                    artist, title = str(row[2]), str(row[3])
                else:
                    artist, title = split_raw(str(row[1]))
                a, t = norm(artist), norm(title)
                if a and t:
                    songs.setdefault((a, t), {"raw": make_raw(artist, title), "artist_key": a, "title_key": t})
        wb.close()
    return list(songs.values())


def _guess_from_texts(words: list[str]) -> str:
    # Название на старых слайдах обычно заглавными, исполнитель — обычными буквами
    upper = [w for w in words if w == w.upper() and any(c.isalpha() for c in w)]
    rest = [w for w in words if w not in upper]
    if upper and rest:
        return make_raw(" ".join(rest), " ".join(upper).capitalize())
    return make_raw(" ".join(words[:-1]), words[-1])


def identify_song(texts: list[str], svod: list[dict]) -> tuple[str | None, str]:
    words = [t.strip() for t in texts if t.strip() and not t.strip().isdigit()]
    blob = norm(" ".join(words))
    if not blob:
        return None, ""
    hits = [s for s in svod if s["artist_key"] in blob and s["title_key"] in blob]
    if not hits:
        return _guess_from_texts(words), CHECK_UNKNOWN
    length = lambda s: len(s["artist_key"]) + len(s["title_key"])  # noqa: E731
    hits.sort(key=length, reverse=True)
    rivals = [h for h in hits[1:] if length(h) == length(hits[0]) and h["raw"] != hits[0]["raw"]]
    return hits[0]["raw"], CHECK_AMBIGUOUS if rivals else ""


def _rels(z: zipfile.ZipFile, names: set, part: str) -> dict:
    base, name = posixpath.split(part)
    rels_name = f"{base}/_rels/{name}.rels"
    if rels_name not in names:
        return {}
    out = {}
    for tag in re.findall(r"<Relationship\b[^>]*>", z.read(rels_name).decode("utf-8", "replace")):
        if 'TargetMode="External"' in tag:
            continue
        rid = re.search(r'\bId="([^"]+)"', tag).group(1)
        target = re.search(r'\bTarget="([^"]+)"', tag).group(1)
        out[rid] = target.lstrip("/") if target.startswith("/") else posixpath.normpath(posixpath.join(base, target))
    return out


def scan_presentation(path: str, svod: list[dict]) -> list[dict]:
    found, image_use = [], Counter()
    with zipfile.ZipFile(path) as z:
        names = set(z.namelist())
        slides = sorted(
            (n for n in names if re.fullmatch(r"ppt/slides/slide\d+\.xml", n)),
            key=lambda n: int(re.search(r"(\d+)\.xml$", n).group(1)),
        )
        for part in slides:
            rels = _rels(z, names, part)
            media = [m.lower() for m in rels.values()]
            if not any(m.endswith(AUDIO_EXT) for m in media) or any(m.endswith(VIDEO_EXT) for m in media):
                continue
            xml = z.read(part).decode("utf-8", "replace")
            texts = [html.unescape(t) for t in re.findall(r"<a:t>([^<]*)</a:t>", xml)]
            raw, check = identify_song(texts, svod)
            if raw is None:
                continue
            pics = []
            for pic in re.findall(r"<p:pic>.*?</p:pic>", xml, re.S):
                if "audioFile" in pic or "videoFile" in pic:
                    continue
                emb = re.search(r'r:embed="([^"]+)"', pic)
                ext = re.search(r'<a:ext cx="(\d+)" cy="(\d+)"', pic)
                target = rels.get(emb.group(1), "") if emb else ""
                if ext and target.lower().endswith(IMAGE_EXT):
                    pics.append((target, int(ext.group(1)) * int(ext.group(2))))
            for target in {p[0] for p in pics}:
                image_use[target] += 1
            found.append({"raw": raw, "check": check, "source": path.replace("\\", "/"),
                          "slide_part": part, "pics": pics, "has_trim": "<p14:trim" in xml})
    limit = max(2, DECOR_SHARE * len(found))
    for f in found:
        photos = [p for p in f.pop("pics") if image_use[p[0]] < limit]
        f["photo_part"] = max(photos, key=lambda p: p[1])[0] if photos else None
    return found


def choose_best(entries: list[dict]) -> list[dict]:
    """Из дублей одной песни — лучший слайд: узнан уверенно, есть фото, задана обрезка."""
    groups = {}
    for e in entries:
        groups.setdefault(norm(e["raw"]), []).append(e)
    result = []
    for group in groups.values():
        group.sort(key=lambda e: (e["check"] != "", e["photo_part"] is None, not e["has_trim"]))
        best = dict(group[0])
        best["spares"] = [{"source": e["source"], "slide_part": e["slide_part"]} for e in group[1:]]
        result.append(best)
    return sorted(result, key=lambda e: e["raw"].lower())
```

XML правится строковыми заменами, а не через ElementTree: ElementTree переименовывает префиксы пространств имён, и PowerPoint ломается на `mc:Ignorable`.

```python
# Один слайд старой игры → отдельный .pptx, без PowerPoint: копия архива, в которой оставлен
# только этот слайд и всё, на что он ссылается (звук, картинки, макет, тема)
import posixpath
import re
import zipfile

SLIDE_REL = "http://schemas.openxmlformats.org/officeDocument/2006/relationships/slide"
CONTENT_TYPES = "[Content_Types].xml"


def _rels_path(part: str) -> str:
    base, name = posixpath.split(part)
    return f"{base}/_rels/{name}.rels" if base else f"_rels/{name}.rels"


def _rel_tags(xml: str) -> list[str]:
    return re.findall(r"<Relationship\b[^>]*>", xml)


def _attr(tag: str, name: str) -> str:
    m = re.search(rf'\b{name}="([^"]*)"', tag)
    return m.group(1) if m else ""


def _resolve(base: str, target: str) -> str:
    return target.lstrip("/") if target.startswith("/") else posixpath.normpath(posixpath.join(base, target))


def extract_slide(src: str, slide_part: str, out_path: str) -> None:
    with zipfile.ZipFile(src) as zin:
        names = set(zin.namelist())
        if slide_part not in names:
            raise ValueError(f"В {src} нет слайда {slide_part}")
        changed: dict[str, str] = {}

        # 1. Связи презентации: убрать все слайды, кроме нужного
        pres_rels_name = "ppt/_rels/presentation.xml.rels"
        pres_rels = zin.read(pres_rels_name).decode("utf-8")
        keep_rid = None
        for tag in _rel_tags(pres_rels):
            if _attr(tag, "Type") != SLIDE_REL:
                continue
            if _resolve("ppt", _attr(tag, "Target")) == slide_part:
                keep_rid = _attr(tag, "Id")
            else:
                pres_rels = pres_rels.replace(tag, "")
        changed[pres_rels_name] = pres_rels

        # 2. Список слайдов, разделы и произвольные показы в presentation.xml
        pres = zin.read("ppt/presentation.xml").decode("utf-8")
        keep_id = None
        for tag in re.findall(r"<p:sldId\b[^>]*/>", pres):
            if f'r:id="{keep_rid}"' in tag:
                keep_id = _attr(tag, "id")
            else:
                pres = pres.replace(tag, "")
        pres = re.sub(r'<p14:sldId id="(\d+)"\s*/>', lambda m: m.group(0) if m.group(1) == keep_id else "", pres)
        pres = re.sub(r"<p:custShowLst>.*?</p:custShowLst>", "", pres, flags=re.S)
        changed["ppt/presentation.xml"] = pres

        # 3. Ссылки нашего слайда на другие слайды → на него самого
        slide_rels_name = _rels_path(slide_part)
        if slide_rels_name in names:
            srels = zin.read(slide_rels_name).decode("utf-8")
            own = posixpath.basename(slide_part)
            for tag in _rel_tags(srels):
                if _attr(tag, "Type") == SLIDE_REL:
                    srels = srels.replace(tag, re.sub(r'\bTarget="[^"]*"', f'Target="{own}"', tag))
            changed[slide_rels_name] = srels

        def read_text(name: str) -> str:
            return changed[name] if name in changed else zin.read(name).decode("utf-8", "replace")

        # 4. Обход связей от корня: оставляем только то, до чего можно дойти
        keep: set[str] = set()
        queue = ["_rels/.rels"]
        while queue:
            rels_name = queue.pop()
            if rels_name in keep or rels_name not in names:
                continue
            keep.add(rels_name)
            owner_base = posixpath.dirname(posixpath.dirname(rels_name))
            for tag in _rel_tags(read_text(rels_name)):
                if _attr(tag, "TargetMode") == "External":
                    continue
                part = _resolve(owner_base, _attr(tag, "Target"))
                if part in names and part not in keep:
                    keep.add(part)
                    queue.append(_rels_path(part))

        # 5. Типы содержимого — без удалённых частей
        ct = zin.read(CONTENT_TYPES).decode("utf-8")
        ct = re.sub(r'<Override\b[^>]*PartName="/([^"]+)"[^>]*/>',
                    lambda m: m.group(0) if m.group(1) in keep else "", ct)
        changed[CONTENT_TYPES] = ct
        keep.add(CONTENT_TYPES)

        with zipfile.ZipFile(out_path, "w") as zout:
            for info in zin.infolist():
                if info.filename not in keep:
                    continue
                if info.filename in changed:
                    zout.writestr(info, changed[info.filename].encode("utf-8"), compress_type=zipfile.ZIP_DEFLATED)
                else:
                    with zin.open(info) as fsrc, zout.open(info, "w") as fdst:
                        while chunk := fsrc.read(1 << 20):
                            fdst.write(chunk)
```

# Банк старых слайдов: каждая песня из старых игр — отдельный файл, плюс каталог и отчёт.
# Запуск из корня проекта: python -m scripts.build_old_bank
import glob
import json
import os

import openpyxl
from openpyxl.styles import Font, PatternFill

from scripts import paths
from scripts.old_slides import choose_best, load_svod_songs, scan_presentation
from scripts.slide_split import extract_slide
from scripts.song_names import safe_filename

REPORT = f"{paths.SOURCES}/Банк старых слайдов — отчёт.xlsx"


def assign_file_names(catalog: list[dict]) -> None:
    used = set()
    for entry in catalog:
        name = safe_filename(entry["raw"])
        while name.lower() in used:
            name += "_"
        used.add(name.lower())
        entry["file"] = name + ".pptx"


def _write_report(catalog: list[dict], path: str) -> None:
    wb = openpyxl.Workbook()
    ws = wb.active
    ws.title = "Сводка"
    ws.append(["Песен в банке", len(catalog)])
    ws.append(["Требуют проверки", sum(1 for c in catalog if c["check"])])
    ws.append(["Без фото", sum(1 for c in catalog if not c["photo_part"])])
    for title, rows in (("Все песни", catalog), ("Проверить", [c for c in catalog if c["check"]])):
        sheet = wb.create_sheet(title)
        sheet.append(["Песня", "Файл", "Проверить", "Фото", "Источник", "Слайд", "Запасных"])
        for c in rows:
            sheet.append([c["raw"], c["file"], c["check"], "да" if c["photo_part"] else "нет",
                          c["source"], c["slide_part"], len(c["spares"])])
        for cell in sheet[1]:
            cell.font = Font(bold=True)
            cell.fill = PatternFill("solid", fgColor="FFE699")
        for col, width in zip("ABCDEFG", (48, 50, 40, 8, 70, 24, 10)):
            sheet.column_dimensions[col].width = width
        sheet.freeze_panes = "A2"
    wb.save(path)


def build_old_bank(old_design: str = paths.OLD_DESIGN, bank_dir: str = paths.OLD_BANK,
                   catalog_path: str = paths.OLD_CATALOG, log=print) -> list[dict]:
    svod = load_svod_songs(old_design)
    entries = []
    for pres in sorted(glob.glob(os.path.join(old_design, "*", "*", "*.pptx"))):
        log(f"читаю {os.path.relpath(pres, old_design)}")
        entries += scan_presentation(pres, svod)
    catalog = choose_best(entries)
    assign_file_names(catalog)
    os.makedirs(bank_dir, exist_ok=True)
    for i, entry in enumerate(catalog, 1):
        out = os.path.join(bank_dir, entry["file"])
        if not os.path.exists(out):  # повторный запуск докачивает только недостающее
            extract_slide(entry["source"], entry["slide_part"], out)
        if i % 100 == 0:
            log(f"нарезано {i} из {len(catalog)}")
    with open(catalog_path, "w", encoding="utf-8") as f:
        json.dump(catalog, f, ensure_ascii=False, indent=1)
    _write_report(catalog, REPORT)
    return catalog


if __name__ == "__main__":
    result = build_old_bank()
    print(f"Готово: {len(result)} песен")
```

# Общий банк песен: видео-караоке (новый банк) + старые слайды (фото + звук) в одном списке
import json
import os

import openpyxl
from openpyxl.styles import Font, PatternFill

from scripts import paths
from scripts.song_bank import load_song_bank
from scripts.song_names import norm


def _blank(raw: str) -> dict:
    return {"raw": raw, "video_file": None, "old_file": None, "old_photo_part": None, "old_source": "", "check": ""}


def merge_banks(video_songs: list[str], video_files: set[str], old_catalog: list[dict]) -> list[dict]:
    entries: dict[str, dict] = {}
    for raw in video_songs:
        entry = entries.setdefault(norm(raw), _blank(raw))
        if f"{raw}.pptx" in video_files:
            entry["video_file"] = f"{raw}.pptx"
    for old in old_catalog:
        entry = entries.setdefault(norm(old["raw"]), _blank(old["raw"]))
        entry.update(old_file=old["file"], old_photo_part=old["photo_part"],
                     old_source=f"{old['source']} / {old['slide_part']}", check=old["check"])
    return sorted(entries.values(), key=lambda e: e["raw"].lower())


def build_common_bank(song_bank: str = paths.SONG_BANK, archive: str = paths.SLIDES_ARCHIVE,
                      old_catalog: str = paths.OLD_CATALOG) -> list[dict]:
    with open(old_catalog, encoding="utf-8") as f:
        old = json.load(f)
    video = [s["raw"] for s in load_song_bank(song_bank)]
    return merge_banks(video, set(os.listdir(archive)), old)


def save_common_bank(entries: list[dict], xlsx_path: str = paths.COMMON_BANK_XLSX,
                     json_path: str = paths.COMMON_BANK_JSON) -> None:
    with open(json_path, "w", encoding="utf-8") as f:
        json.dump(entries, f, ensure_ascii=False, indent=1)
    wb = openpyxl.Workbook()

# Слот «Игровой слайд» шаблона «Рабочий 2 вар» ← песня из банка старых слайдов:
# фото в рамку (python-pptx), название/исполнитель и звук с автозапуском (PowerPoint COM)
import io
import os
import zipfile

from pptx import Presentation
from pptx.enum.shapes import PP_PLACEHOLDER

from scripts.ppt_paste import copy_paste_checked

MSO_GROUP = 6
MSO_MEDIA = 16
MAX_TITLE_LINES = 2  # правило оператора: название — не больше двух строк, иначе меньше шрифт
MIN_TITLE_SIZE = 20
MIN_ARTIST_SIZE = 16
LINE_SLACK = 1.1  # запас на неровную высоту строк


def insert_photos(pptx_path: str, photos: dict[int, tuple[str, str]]) -> None:
    if not photos:
        return
    prs = Presentation(pptx_path)
    for slide_number, (old_file, photo_part) in photos.items():
        slide = prs.slides[slide_number - 1]
        frame = next((p for p in slide.placeholders if p.placeholder_format.type == PP_PLACEHOLDER.PICTURE), None)
        if frame is None:
            raise LookupError(f"На слайде {slide_number} нет рамки под фото — это не слот «Игровой слайд»")
        with zipfile.ZipFile(old_file) as z:
            frame.insert_picture(io.BytesIO(z.read(photo_part)))  # обрезка по рамке без искажений
    prs.save(pptx_path)


def _text_boxes(slide):
    for shape in slide.Shapes:
        if shape.Type == MSO_GROUP:
            boxes = [g for g in shape.GroupItems if g.HasTextFrame]
            if len(boxes) == 2:
                return sorted(boxes, key=lambda b: b.Top)  # сверху название, снизу исполнитель
    raise LookupError("В слоте нет заготовки названия и исполнителя")


def _fit_lines(box, text: str, max_lines: int, min_size: float) -> None:
    """Вписывает текст не больше чем в max_lines строк, уменьшая шрифт только если не влезает."""
    rng = box.TextFrame.TextRange
    size0 = rng.Font.Size
    rng.Text = "А"
    line0 = rng.BoundHeight  # высота одной строки при исходном размере
    rng.Text = text
    while rng.BoundHeight > max_lines * line0 * rng.Font.Size / size0 * LINE_SLACK and rng.Font.Size > min_size:
        rng.Font.Size = rng.Font.Size - 2


def _put_title_and_artist(slide, title: str, artist: str) -> None:
    title_box, artist_box = _text_boxes(slide)
    height_before = title_box.Height
    _fit_lines(title_box, title.upper(), MAX_TITLE_LINES, MIN_TITLE_SIZE)
    _fit_lines(artist_box, artist, 1, MIN_ARTIST_SIZE)
    # Название стало выше или ниже заготовки (две строки в «НА 1 СТРОЧКУ» или одна в «2 СТРОЧКИ»):
    # раздвигаем или сдвигаем название и исполнителя поровну — как в заготовке на две строки
    shift = (title_box.Height - height_before) / 2
    title_box.Top = title_box.Top - shift
    artist_box.Top = artist_box.Top + shift


def fill_old_slot(ppt_app, prs, slide_number: int, old_file: str, title: str, artist: str) -> None:
    slide = prs.Slides(slide_number)
    _put_title_and_artist(slide, title, artist)

    old = ppt_app.Presentations.Open(os.path.abspath(old_file), ReadOnly=True, WithWindow=False)
    try:
        audio = next((s for s in old.Slides(1).Shapes if s.Type == MSO_MEDIA), None)
        if audio is None:
            raise LookupError(f"В «{os.path.basename(old_file)}» нет звука")
        # обрезка, затухание и громкость хранятся в самой фигуре звука и переносятся вместе с ней
        pasted = copy_paste_checked(audio.Copy, slide, audio.Name, MSO_MEDIA)
    finally:
        old.Close()

    sound = pasted(1)
    sound.Left = -sound.Width - 10  # значок за левым краем: не виден и не закрывает кнопку макета
    sound.Top = 0
    play = sound.AnimationSettings.PlaySettings
    play.PlayOnEntry = True  # звук сам включается при открытии слайда
    play.HideWhileNotPlaying = True
```

# Вид слайда у бочонка: "video" — караоке из видео-банка, "old" — старый слайд (фото + звук).
# В смешанной игре бочонки, кратные 3, — старые слайды, остальные — видео.
KIND_NAMES = {"video": "видео", "old": "старый слайд"}


def is_mixed(barrels: list[dict]) -> bool:
    return any(b.get("kind") == "old" for b in barrels)


def check_kinds(barrels: list[dict], bank_by_raw: dict[str, dict]) -> list[str]:
    mixed = is_mixed(barrels)
    errors = []
    for b in barrels:
        number, song, kind = b["number"], b["song"], b.get("kind", "video")
        if kind not in KIND_NAMES:
            errors.append(f"Бочонок {number}: непонятный вид «{kind}»")
            continue
        want = "old" if mixed and number % 3 == 0 else "video"
        if kind != want:
            errors.append(f"Бочонок {number} («{song}»): здесь должен быть {KIND_NAMES[want]}, а стоит {KIND_NAMES[kind]}")
            continue
        entry = bank_by_raw.get(song, {})
        if kind == "old" and not entry.get("old_file"):
            errors.append(f"Бочонок {number}: у песни «{song}» нет старого слайда")
        if kind == "video" and not entry.get("video_file"):
            errors.append(f"Бочонок {number}: у песни «{song}» нет видео")
    return errors


def resolve_files(barrels: list[dict], bank_by_raw: dict[str, dict]) -> list[dict]:
    resolved = []
    for b in barrels:
        entry = bank_by_raw[b["song"]]
        kind = b.get("kind", "video")

import json


def export_selection(selected: list[str], output_path: str, kinds: list[str] | None = None) -> None:

    template_path: str,

    resolved = []

        folder = old_bank_folder if kind == "old" else archive_folder
        song_file = os.path.join(folder, barrel.get("file") or f"{barrel['song']}.pptx")
        if not os.path.exists(song_file):
            raise FileNotFoundError(f"Не найден файл для бочонка {barrel['number']}: {barrel['song']}")
        resolved.append((barrel, os.path.abspath(song_file)))

    # 2. Номера слайдов-слотов — без PowerPoint
    prs_readonly = Presentation(template_path)
    slot = {b["number"]: find_slide_index_by_barrel_number(prs_readonly, b["number"]) + 1 for b, _ in resolved}

    # 3. Работаем на копии; фото старых песен — в рамки шаблона до PowerPoint (python-pptx)
    output_path = os.path.abspath(output_path)
    shutil.copy(template_path, output_path)
    insert_photos(output_path, {
        slot[b["number"]]: (f, b["photo_part"])
        for b, f in resolved if b.get("kind") == "old" and b.get("photo_part")
    })

    ppt_app = win32.Dispatch("PowerPoint.Application")
    try:
        template_prs = ppt_app.Presentations.Open(output_path, WithWindow=False)
        try:
            for barrel, song_file in resolved:

                    artist, title = split_raw(barrel["song"])
                    fill_old_slot(ppt_app, template_prs, slot[barrel["number"]], song_file, title, artist)
                else:
                    insert_song_slide(ppt_app, template_prs, song_file, slot[barrel["number"]])
            template_prs.Save()
        finally:
            template_prs.Close()
    finally:

import json
import os

from scripts import paths
from scripts.barrel_kinds import check_kinds, is_mixed, resolve_files
from scripts.build_presentation import assemble_presentation
from scripts.generate_blanks import generate_blanks
from scripts.song_bank import load_song_bank
from scripts.validate_selection import validate_selection

BLANKS_NAME = "Бланки.xlsm"
PRESENTATION_NAME = "Презентация.pptx"


def _load_bank(song_bank: str) -> list[dict]:
    if os.path.exists(paths.COMMON_BANK_JSON):
        from scripts.common_bank import load_common_bank
        return load_common_bank()
    # общий банк ещё не собран — работаем только с видео-банком, как раньше
    return [{"raw": s["raw"], "video_file": f"{s['raw']}.pptx", "old_file": None, "old_photo_part": None}
            for s in load_song_bank(song_bank)]


def run_pipeline(
    selected_songs_path: str,
    n_individual: int,
    n_team: int,
    output_dir: str,
    blanks_template: str = paths.BLANKS_TEMPLATE,
    presentation_template: str | None = None,
    archive_folder: str = paths.SLIDES_ARCHIVE,
    song_bank: str = paths.SONG_BANK,
) -> dict:
    with open(selected_songs_path, encoding="utf-8") as f:
        barrels = sorted(json.load(f)["barrels"], key=lambda b: b["number"])
    songs_in_order = [b["song"] for b in barrels]

    # Всё проверяем до запуска Excel и PowerPoint: сборка долгая, падать на середине обидно
    bank = _load_bank(song_bank)
    check = validate_selection(songs_in_order, bank)
    if not check["ok"]:
        raise ValueError("Список песен не прошёл проверку: " + "; ".join(check["errors"]))
    if [b["number"] for b in barrels] != list(range(1, 91)):
        raise ValueError("Номера бочонков должны идти от 1 до 90 без пропусков")
    by_raw = {e["raw"]: e for e in bank}
    kind_errors = check_kinds(barrels, by_raw)
    if kind_errors:
        raise ValueError("Виды слайдов не на своих местах: " + "; ".join(kind_errors))
    if presentation_template is None:
        presentation_template = paths.MIXED_TEMPLATE if is_mixed(barrels) else paths.PRESENTATION_TEMPLATE

    blanks_path = os.path.join(output_dir, BLANKS_NAME)
    generate_blanks(blanks_template, blanks_path, songs_in_order, n_individual, n_team)

    presentation_path = os.path.join(output_dir, PRESENTATION_NAME)
    assemble_presentation(presentation_template, archive_folder, resolve_files(barrels, by_raw), presentation_path)

    return {"blanks_path": blanks_path, "presentation_path": presentation_path}
