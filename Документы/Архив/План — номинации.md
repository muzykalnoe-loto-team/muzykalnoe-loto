# Слайды номинаций — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в собранной игре — ровно одна номинация на раунд (тематическая, нарисованная Claude, или по очереди / по выбору оператора), кнопки 1–3 на «Таблице» ведут на них, тематические слайды копятся в архиве.

**Architecture:** чистая логика выбора и история — `scripts/nominations.py`; рисование иллюстрации (SVG → PNG через Edge) и образцы сцен — `scripts/theme_art.py`, `scripts/theme_scenes.py`; работа с презентацией через PowerPoint COM — `scripts/nomination_slides.py` (заполнить тематический слайд, удалить лишние, перепривязать кнопки, превью двух вариантов, архив). `run_pipeline` вызывает это после вставки песен. Панель хранит выбор оператора в брифе; скилл «номинация» описывает Claude, как придумать и показать два варианта.

**Tech Stack:** Python 3.13, pywin32 (PowerPoint COM), python-pptx, Microsoft Edge headless, pytest.

**Spec:** `Спецификация — номинации.md`

## Global Constraints

- Шаблон — `paths.PRESENTATION_TEMPLATE` («Рабочий 2 вар»); сам файл шаблона не меняется.
- Слайды номинаций в шаблоне (номер слайда → внутренний SlideID, он не меняется при удалении других слайдов): раунд 1 — 10 «Тематическая» (374), 11 «Щас спою!» (375), 12 «Крик души» (258); раунд 2 — 110 «Синяя богиня» (259), 111 «Пьяная вишня» (376); раунд 3 — 114 «Танцпол в огне» (377), 115 «Мы без тормозов» (378).
- Кнопки на слайде 15 «Таблица» (низ, Top ≈ 485 pt): «1» — Left ≈ 505, «2» — Left ≈ 594, «3» — Left ≈ 679 (ширина 41). Остальные кнопки слайда 15 не трогать. Имена фигур не использовать (COM и python-pptx отдают их на разных языках).
- Тематический слайд (стиль «вариант Б»): фон макета «Тематическая» без картинки «рок»; заголовок в заготовке слайда 10, Unbounded 80 пт, ровно две строки (перенос строки — символ `\v`); под заголовком строка `НОМИНАЦИЯ «САМАЯ КОСТЮМИРОВАННАЯ КОМАНДА»` — Unbounded 15 пт, цвет темы; иллюстрация — PNG 1920×1080 с прозрачным фоном на весь слайд, под заголовком и кнопками.
- Без нейросетей и платных сервисов; рисует Claude кодом (SVG).
- Архив `Исходники/Номинация.pptx` — **Claude не читает**: код только дописывает в конец и ничего не выводит о содержимом.
- Закрывать PowerPoint только если `Presentations.Count == 0`; `python`, не `python3`; ответы оператору — по-русски, с полным путём к файлам.
