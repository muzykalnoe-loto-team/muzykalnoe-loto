## Исходные файлы оператора (`Исходники/`, не в git; пути — `scripts/paths.py`)

- `Банк песен.xlsx` — лист `2301`: колонка A = номер, B = `"Исполнитель - Название"`.
- `Шаблон бланков.xlsm` — лист `Список` (B2:B91 = 90 песен, E1/E2 = число индивидуальных/командных
  бланков). Бланки формирует VBA-макрос `GenerateBlanks.GenerateAllBlanks` — одной записи
  значений в ячейки недостаточно.
- `Рабочий 2 вар.pptx` — единственный шаблон презентации (`paths.PRESENTATION_TEMPLATE`),
  118 слайдов; слайды 16–105 — 90 слотов-заглушек под бочонки (фигура `"Текст 9"` с номером).
  Каждый 3-й слот (бочонки 3, 6 … 90) — макет «Игровой слайд» под старый слайд (фото + звук),
  кнопка «Таблица» у него в макете; слои снизу вверх: фото (заготовка) → «Круг под номером» (тёмный
  круг, `Исходники/Круг под номером.png`, добавлен 25.10.2026 по просьбе оператора; копия шаблона до этого —
  `Исходники/Рабочий 2 вар — до круга.pptx`) → номер бочонка «Текст 9»; остальные — «Игровой слайд
  караоке» под видео. Слоты уже
  содержат навигацию с гиперссылками — **слайд целиком не заменять**, только добавлять фигуры
  поверх (`scripts/ppt_paste.py`). Номинации: слайды 10–12, 110–111, 114–115 (SlideID — в
  `scripts/nominations.py`), кнопки 1–3 на слайде 15 «Таблица».
- `Банк всех слайдов23.01.2026/` — по файлу `"Исполнитель - Название.pptx"` на песню, слайд с видео.
- `Старый дизайн/` — старые игры (≈55 ГБ), **только чтение**.
- `Банк старых слайдов/` — сжатый файл на песню из старых игр (фото + отрывок звука с запасом
  5 с), `каталог.json`, `правки оператора.json`; `python -m scripts.build_old_bank`.
- `Общий банк песен.xlsx/.json` — все песни (видео и старые слайды) одной строкой;
  `python -m scripts.common_bank`. Подбор и панель берут песни отсюда.
- `Номинация.pptx` — архив тематических слайдов. **Не читать**; программа только дописывает.
- `Номинация — образец стиля.pptx` — пять одобренных тематических слайдов (образец стиля).

## Модули `scripts/`

- `paths.py` — где лежат файлы; `EVENTS = "Выгрузка ИИ"` — папка готовых игр.
- `song_names.py` — нормализация названий (`norm`, `split_raw`).
- `old_slides.py`, `slide_split.py`, `compact_slide.py`, `build_old_bank.py` — банк старых слайдов:
  узнать песню в старой игре, вырезать слайд, сжать (mp3 режется по «часам PowerPoint»), собрать банк.
- `common_bank.py` — общий банк песен.
- `barrel_kinds.py` — вид слайда у бочонка; на 3, 6 … 90 — обязательно старый слайд.
- `old_slot.py` — заполнение слота старой песней (фото, название, звук).
- `song_bank.py`, `validate_selection.py`, `export_selection.py` — база, проверка списка
  (90, без дублей, всё в базе, без стоп-листа), запись `selected_songs.json`.
- `stop_list.py` — стоп-лист исполнителей (`Стоп-лист исполнителей.xlsx`, `paths.STOP_LIST`).
- `generate_blanks.py` — бланки через Excel COM.
- `template_slots.py` — слот по номеру бочонка (python-pptx).
- `ppt_paste.py` — вставка слайда песни поверх слота (PowerPoint COM, через буфер обмена —
  во время сборки оператору нельзя копировать).
- `build_presentation.py` — сборка презентации.
- `nominations.py` — номинация каждого раунда (выбор в брифе или по очереди), история
  `Выгрузка ИИ/номинации — история.json`.
- `theme_art.py`, `theme_scenes.py` — иллюстрация тематического слайда (SVG → PNG через Edge),
  пять образцов сцен.
- `nomination_slides.py` — номинации в игре (лишние удаляются, кнопки 1–3 «Таблицы»),
  превью двух вариантов, дописывание в архив.
- `yandex_disk.py` — загрузка папки игры на Яндекс Диск («Музыкальное лото/<дата> <тема>»),
  публичная ссылка и ярлык «Файлы на Яндекс Диске.url» в папке игры.
- `run_pipeline.py` — оркестратор: `selected_songs.json` → `Бланки.xlsm` и `Презентация.pptx`
  (+ номинации, предупреждение при размере > 995 МБ).

## Проверка игр второго человека

Отдельной программы нет: проверка идёт по скиллу `proverit-igru` из существующих модулей
(`nominations`, `nomination_slides`, `stop_list`, `song_names`) и PowerPoint COM. Номер бочонка на
слайде искать по тексту-числу вверху слайда, не по имени фигуры (COM и python-pptx называют
фигуры по-разному). Порядок анимации — `Slide.TimeLine.MainSequence`: первым эффект медиа,
не «по щелчку».

## Панель мероприятий

`artifact/index.html` — веб-форма (Claude Artifact) https://claude.ai/artifact/QNGUxwrX1AHnyPGuPrzMWN:
бриф, статусы стадий, ссылка «Скачать файлы». Данные — `ArtifactData`, коллекция `events`
(поля: `theme`, `date`, `time`, `place`, `n_individual`, `n_team`, `wanted_songs`,
`themed_nomination`, `nomination_1..3`, `stages` {songs, blanks, presentation}: draft /
in_progress / review / approved, `status`, `files_url`; от кнопки «следующий шаг» — `request`
{step: songs|build, state: waiting|taken, at, note}; от Claude — `songs_list`, `claude_note`,
`theme_variants` [{url, title}] (картинки — ассеты панели), `theme_choice`). Кнопки на сайте
ставят `request`, Claude на компьютере оператора забирает его скиллом `dezhurstvo`. Публикуется собранный
`artifact/dist/index.html` со встроенным банком песен: `python artifact/build_panel.py`,
затем publish с этим `url`. `dist/` в git не хранится.
