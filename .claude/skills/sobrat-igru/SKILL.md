# Собрать игру по брифу с сайта

Пользователь — оператор, не разработчик: простые слова, каждый файл — ссылкой и **полным путём
от диска** (`C:\Users\User\Documents\Курсы\API\ДВИЖ дз\Выгрузка ИИ\…`). Как устроен код —
`Документы/Устройство программы.md` (открывай, только если что-то сломалось).

Порядок ниже — с тремя остановками для оператора. Не перескакивай через них.

## 1. Найти бриф

Панель: https://claude.ai/artifact/QNGUxwrX1AHnyPGuPrzMWN. `ArtifactData`, действие `list`,
коллекция `events`. Брифы со стадией `songs` = `draft` — новые. Один — бери его; несколько —
спроси, какой; ни одного — попроси заполнить бриф на сайте (ярлык `Панель мероприятий.url`).

Перескажи бриф одной строкой (тема, дата, время, место, бланков, песни по желанию, номинации)
и сразу начинай.

- Папка игры: `Выгрузка ИИ/<ДД.ММ.ГГГГ> <тема>` (например `Выгрузка ИИ/31.10.2026 Готический бал`).
- В панели: `ArtifactData` `update` документа — `stages` целиком
  `{"songs": "in_progress", "blanks": "draft", "presentation": "draft"}`.

## 2. Список песен — остановка 1

Скилл `podobrat-pesni`: условия — тема брифа, песни по желанию — `wanted_songs`, папка — из шага 1.
Excel `Список песен.xlsx` в папке игры. В панели `stages.songs` = `review`.

**Остановись:** оператор утверждает список в чате или кнопкой «Утвердить» в панели. Правки —
по скиллу. После утверждения — `selected_songs.json` (по скиллу) и `stages.songs` = `approved`.

## 3. Номинации — остановка 2 (только тематическая игра)

Скилл `nominatsiya`. Галочки `themed_nomination` нет — остановки нет, номинации берутся из брифа.
Галочка есть — два варианта тематического слайда, **остановись** и жди выбора.

## 4. Бланки и презентация

Попроси оператора ничего не копировать минут 10–15 (сборка пользуется буфером обмена).
`stages.blanks` и `stages.presentation` = `in_progress`. Запусти в фоне:

```python
from scripts.run_pipeline import run_pipeline
result = run_pipeline(f"{folder}/selected_songs.json", brief["n_individual"], brief["n_team"], folder,
                      event=brief["theme"], event_date=brief["date"], nominations={...})  # как в nominatsiya
```

Ошибка сборки — перескажи простыми словами, что не так (например, файл песни не открывается —
предложи замену песни через `podobrat-pesni`), не повторяй вслепую.

## 5. Яндекс Диск и панель

```python
from scripts.yandex_disk import upload_event
url = upload_event(folder, ["Список песен.xlsx", "Бланки.xlsm", "Презентация.pptx"])
```

Ключ — только через программу; `.env` не читать. Нет ключа — скажи оператору вписать
`YANDEX_DISK_TOKEN` в `.env` самому. Загрузка ~1 ГБ идёт долго — в фоне.

В панели: `files_url` = `url`, `stages.blanks` и `stages.presentation` = `review`.

## 6. Показать результат — остановка 3

Одним сообщением: папка игры (полный путь), файлы (`Бланки.xlsm`, `Презентация.pptx`, размер),
номинации по раундам (`result["nominations"]` названиями), предупреждения
(`result["warning"]`), ссылка на Яндекс Диск. Попроси проверить и утвердить бланки и презентацию
кнопками «Утвердить» в панели. Допиши `отчёт.md` (папка `Выгрузка ИИ/` в git не попадает —
коммить только изменения проекта, если были).
