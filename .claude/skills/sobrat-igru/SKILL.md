# Собрать игру по брифу с сайта

Пользователь — оператор, не разработчик: простые слова, каждый файл — ссылкой и **полным путём
от диска** (`C:\Users\User\Documents\Курсы\API\ДВИЖ дз\Выгрузка ИИ\…`). Как устроен код —
`Документы/Устройство программы.md` (только если что-то сломалось).

Панель: https://claude.ai/artifact/QNGUxwrX1AHnyPGuPrzMWN, `ArtifactData`, коллекция `events`.
Все записи в документ мероприятия — `update` с `if_version`. Оператор управляет кнопками на
сайте: «Подобрать песни» → «Утвердить» список (или «Отправить правки») → «Собрать игру»
(для тематической — сначала выбор одного из двух вариантов) → «Утвердить» бланки и презентацию.

**Папка игры:** `Выгрузка ИИ/<ДД.ММ.ГГГГ> <тема>` (дата брифа `2026-11-14` → `14.11.2026`),
например `Выгрузка ИИ/14.11.2026 Гэтсби`.

## Шаги с сайта

### `songs` — подобрать песни (или правки `request.note`)

1. `stages.songs` = `in_progress` (вместе с отметкой `taken`, если пришло из дежурства).
2. Скилл `podobrat-pesni`: условия — тема брифа, песни по желанию — `wanted_songs`; правки —
   по `request.note` к прежнему списку (`selected_songs.json` в папке игры). Остановку «показать
   на утверждение» заменяет сайт: сразу сохрани `Список песен.xlsx` **и** `selected_songs.json`.
3. Загрузи список на Яндекс Диск (в ту же папку, куда потом ляжет игра):
   `url = upload_event(folder, ["Список песен.xlsx"])` (`from scripts.yandex_disk import upload_event`).
4. На сайт одной записью: `songs_list` = `[{"n": 1, "song": "…", "kind": "video"|"old"}, …]`
   (все 90), `files_url` = `url`, `stages.songs` = `review`, `request` удалить, `claude_note` — сколько исполнителей,
   что учтено, сомнения, «проверьте список и нажмите «Утвердить» или напишите правки».

### `build` — собрать игру

Проверь: `stages.songs` == `approved`, `selected_songs.json` есть. Нет — `claude_note`, выход.

**Тематическая игра** (`themed_nomination`), `theme_choice` ещё нет:
1. Скилл `nominatsiya`, шаг 2–3: два варианта, `preview_variants` в `<папка игры>/номинация`.
   Сохрани рядом `варианты.json`: `[{"title", "glow", "art_png", "name"}]` (рисунки — `res["arts"]`).
2. Загрузи картинки вариантов (`res["pngs"]`) на сайт: `Artifact` publish, `url` панели,
   `asset: true`, `file_paths` — получишь адреса картинок.
3. На сайт: `theme_variants` = `[{"url": адрес, "title": "заголовок одной строкой"}]`,
   `request` удалить, `claude_note` — «выберите вариант». Дальше ждём кнопку оператора.

**Сборка** (обычная игра, или тематическая с `theme_choice` = номер варианта с 0):
1. `stages.blanks` и `stages.presentation` = `in_progress`. Тема: `варианты.json[theme_choice]`.
2. В фоне (10–20 мин; оператору в это время ничего не копировать — сборка пользуется буфером):
   ```python
   from scripts.run_pipeline import run_pipeline
   result = run_pipeline(f"{folder}/selected_songs.json", brief["n_individual"], brief["n_team"], folder,
       event=brief["theme"], event_date=brief["date"],
       nominations={"themed": brief.get("themed_nomination", False),
                    "choices": {r: brief.get(f"nomination_{r}", "auto") for r in (1, 2, 3)},
                    "theme": theme})  # theme = None для обычной игры
   ```
3. Загрузка (в фоне, ключ — только через программу, `.env` не читать; нет ключа — попроси
   оператора вписать `YANDEX_DISK_TOKEN` в `.env`):
   ```python
   from scripts.yandex_disk import upload_event
   url = upload_event(folder, ["Список песен.xlsx", "Бланки.xlsm", "Презентация.pptx"])
   ```
4. На сайт: `files_url` = `url`, `stages.blanks` и `stages.presentation` = `review`, `request`
   удалить, `claude_note` — номинации по раундам (названиями из `result["nominations"]`),
   размер презентации, предупреждения (`result["warning"]`) простыми словами, «скачайте,
   проверьте, утвердите».
5. Ошибка — перескажи простыми словами (файл песни не открывается — предложи «Отправить
   правки» с заменой песни), стадии верни в `draft`, не повторяй вслепую.
