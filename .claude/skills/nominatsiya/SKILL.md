# Номинации в игре

Пользователь — оператор мероприятий, не разработчик. Пиши простым языком, без терминов.
Каждый созданный файл называй ссылкой и **полным путём от диска**
(`C:\Users\User\Documents\Курсы\API\ДВИЖ дз\…`). Подробности — `Спецификация — номинации.md`.

**Архив `Исходники/Номинация.pptx` не читать** — ни целиком, ни частями. Программа только
дописывает в него; готовые слайды прошлых игр не ищем и не берём: каждый раз новый визуал.

## 1. Прочитать бриф

Бриф — в «Панели мероприятий» (https://claude.ai/artifact/QNGUxwrX1AHnyPGuPrzMWN),
`ArtifactData`, коллекция `events`. Поля:

- `theme` — название мероприятия (тема); `date` — дата;
- `themed_nomination` — `true`: тематическая игра (в 1-м раунде — нарисованный слайд);
- `nomination_1`, `nomination_2`, `nomination_3` — `"auto"` (по очереди) или ключ:
  1-й раунд `sing` «Щас спою!» / `cry` «Крик души»; 2-й `goddess` «Синяя богиня» /
  `cherry` «Пьяная вишня»; 3-й `dancefloor` «Танцпол в огне» / `nobrakes` «Мы без тормозов».
  Полей нет (старый бриф) — всё `"auto"`.

**Обычная игра** (галочки нет): сразу шаг 4 с `theme=None`.

## 2. Тематическая игра: придумать два разных варианта

По названию мероприятия (и теме) — **два заметно разных** варианта. У каждого:

- **Заголовок** — игра слов про наряд / костюм в теме, ЗАГЛАВНЫМИ, ровно две строки через `\v`,
  в строке не больше ~9–10 букв (иначе Unbounded 80 пт перенесёт на третью). Дефис внутри
  слова — `\u2011`. Образцы, которые понравились оператору: «НАРЯДНЫЕ,\vКАК ЁЛКИ»,
  «ТЬМА ВАМ\vК ЛИЦУ», «БЛЕСК\vПО‑ГЭТСБИ», «ПРИКИД\vЧТО НАДО», «ОДЕТЫ\vПО ГОСТУ».
- **Цвет темы** `glow` (`#RRGGBB`) — им же окрашена строка
  «НОМИНАЦИЯ «САМАЯ КОСТЮМИРОВАННАЯ КОМАНДА»» и подсветка фона.
- **Своя сцена** — новая функция `scene(rnd) -> (defs, элементы)` в `scripts/theme_scenes.py`
  по образцу пяти готовых (`newyear`, `gothic`, `gatsby`, `disco90`, `ussr`), с общими
  помощниками из `scripts/theme_art.py` (`bg_glow`, `star_path`, `sparkle`, `GLOW`, `SOFT`).
  Стиль — только «вариант Б»: одна большая векторная иллюстрация справа (силуэты, свечение,
  лучи, частицы), цветная подсветка фона. Холст 1920×1080; рисунок — **x ≥ 1150**, левее
  прозрачно (там заголовок и строка номинации). Угол с кнопкой «Таблица» справа внизу
  можно закрывать — кнопка лежит поверх картинки. Без нейросетей и платных сервисов.
  Если тема совпадает с одной из пяти — всё равно рисуй новую сцену (можно на основе образца).

## 3. Показать оператору и дождаться выбора

```python
from scripts.nomination_slides import preview_variants
res = preview_variants([
    {"title": "…\v…", "glow": "#…", "scene": scene_a, "seed": "a"},
    {"title": "…\v…", "glow": "#…", "scene": scene_b, "seed": "b"},
], "events/<папка мероприятия>/номинация")
```

- Посмотри картинки `res["pngs"]` сам: текст не перекрыт рисунком, заголовок в две строки.
  `res["warnings"]` не пуст — сократи заголовок и повтори, оператору такое не показывай.
- Покажи оператору обе картинки (`res["pngs"]`) и файл `res["pptx"]` с полными путями;
  спроси, какой вариант взять. Просит правки — поправь и покажи снова.
- **Не собирай игру, пока оператор не выбрал.**

## 4. Собрать игру с номинациями

```python
from scripts.run_pipeline import run_pipeline
result = run_pipeline(selected_json, n_individual, n_team, output_dir,
    event=brief["theme"], event_date=brief["date"],
    nominations={
        "themed": brief.get("themed_nomination", False),
        "choices": {1: brief.get("nomination_1", "auto"), 2: brief.get("nomination_2", "auto"),
                    3: brief.get("nomination_3", "auto")},
        "theme": None,  # тематическая: {"title", "glow", "art_png": res["arts"][i], "name": тема}
    })
```

- `art_png` — рисунок выбранного варианта: `res["arts"][номер варианта − 1]`.
- Сборка долгая; попроси оператора ничего не копировать, пока она идёт (сборка пользуется
  буфером обмена).
- `result["nominations"]` — какие номинации вошли: назови оператору их названия по раундам.
- `result["warning"]` не пуст — перескажи простыми словами (например, архив был открыт
  в PowerPoint и слайд не дописан — закрыть архив и дописать позже через
  `append_to_archive`).
- Программа сама запишет игру в историю (для очереди «Авто») и, для тематической, допишет
  слайд в архив «Номинация».
