# Подбор 90 песен для музыкального лото

Пользователь — оператор мероприятий, не разработчик. Пиши простым языком, без терминов.

## Что нужно узнать у пользователя

Если не сказано в запросе, спроси коротко (одним сообщением):
1. Условия подбора: тема, эпоха или годы, жанр или стиль, любая их комбинация — либо «вразнобой».
2. Название папки мероприятия (по умолчанию — тема и дата, например `Новый год 2026-12-25`).
3. Есть ли песни, которые оператор хочет обязательно включить. Если мероприятие заведено в «Панели мероприятий» (https://claude.ai/artifact/QNGUxwrX1AHnyPGuPrzMWN), прочитай его бриф (`ArtifactData`, коллекция `events`): поле `wanted_songs` — список таких песен, строки записаны точно как в базе.

## Как подбирать

1. Загрузи общий банк: `from scripts.common_bank import load_common_bank` → `bank = load_common_bank()` (≈2400 песен; поле `raw` — строка «Исполнитель - Название»; `video_file` — есть видео-караоке, `old_file` — есть старый слайд с фото и звуком). Если файла `Исходники/Общий банк песен.json` нет — собери его: `python -m scripts.common_bank`. Запускай через `python`, не `python3`. Банк не изменяй.
2. В базе нет жанра и года, поэтому подбирай по своим знаниям о песнях. Выгрузи список в текстовый файл в scratchpad и прочитай его целиком, чтобы выбирать из реальных строк, а не по памяти. Если не уверен, подходит ли песня под условие, не бери её или отметь сомнение в колонке «Комментарий».
3. Жёсткие правила:
   - ровно 90 песен;
   - без повторов;
   - **не больше 3 песен одного исполнителя. Правило строгое**, без исключений, даже если тема узкая — в этом случае возьми больше разных исполнителей или сообщи, что песен под тему не хватает, и предложи расширить условия;
   - каждая песня есть в банке, строка `raw` записана в точности как в банке.
   - **Бочонки 3, 6, 9 … 90 (30 шт.) — песни со старым слайдом** (`old_file`), остальные 60 — с видео (`video_file`).
   - **Песня есть в обоих видах — решает популярность:** популярную (её и так знают наизусть) ставь старым слайдом на бочонок, кратный 3; малоизвестную — с видео. Для остальных песен вид не важен.
   - Песня по желанию только со старым слайдом — на бочонок, кратный 3; только с видео — на остальные.
   - **все песни по желанию из брифа (`wanted_songs`) входят в список** и считаются в 90 и в лимит 3 песен на исполнителя. Если они сами нарушают лимит, не выбрасывай их молча — спроси оператора. В Excel в колонке «Комментарий» пометь их «по желанию».
   - **не меньше 5 суперхитов в каждом списке**, какой бы узкой ни была тема. Суперхит — песня, которую знают и подпевают все гости, даже пришедшие без подготовки: эталон — «Жуки - Батарейка»; ещё примеры из базы — «Руки Вверх! - 18 мне уже», «Иванушки International - Тополиный пух», «Ласковый май - Белые розы», «Звери - Районы-кварталы», «Земляне - Трава у дома», «КИНО - Группа крови». Если суперхит подходит под тему — отлично, если нет — всё равно включи. Суперхиты расставь по бочонкам вразброс, а не подряд. В Excel в колонке «Комментарий» пометь их «суперхит» (если песня и по желанию, и суперхит — «по желанию, суперхит»).
4. Если выбор «вразнобой»: случайная выборка (`random.shuffle`), исполнители и годы разные.
5. Порядок бочонков перемешай, чтобы песни по теме не шли подряд.
6. Исполнителя для подсчёта бери как текст до « - » (`from scripts.song_names import split_raw`).

## Показ на утверждение

Сделай Excel-файл `Выгрузка ИИ/<папка мероприятия>/Список песен.xlsx` (openpyxl). Колонки: № бочонка, Исполнитель, Название, Вид («видео» / «старый слайд»), Комментарий (почему подходит или сомнение). Шапка выделена, колонки подогнаны по ширине, первая строка закреплена.

В ответе дай:
- ссылку на файл (markdown-ссылка) и полный путь от диска (`C:\Users\User\Documents\Курсы\API\ДВИЖ дз\Выгрузка ИИ\…`);
- короткую выжимку простыми словами: сколько разных исполнителей, какие условия учтены, что вызвало сомнения;
- вопрос: «Утверждаете список или что-то заменить?»

Замены делай по просьбам пользователя, после каждой правки снова проверяй и обновляй файл.

## После слова «утверждаю»

1. Запиши список: `from scripts.export_selection import export_selection` → `export_selection(selected, "Выгрузка ИИ/<папка>/selected_songs.json", kinds=kinds)` (номера бочонков 1–90 проставляются по порядку; `kinds` — «old» на бочонках 3, 6 … 90, «video» на остальных).
2. Ещё раз проверь `validate_selection` на сохранённом списке.
3. **Остановись.** Скажи, где лежит файл, и что дальше можно сделать бланки и презентацию. Сам их не запускай, жди команду.
