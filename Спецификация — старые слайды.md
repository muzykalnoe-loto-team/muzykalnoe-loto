# Спецификация: старые слайды в новых играх

Дата согласования: 2026-10-08
Статус: решение согласовано с оператором, план работы ещё не составлен

Дополнение к `Спецификация.md` (стадии 1 и 3 пайплайна). Источник истины
по работе со старыми презентациями.

## 1. Зачем

В папке `Исходники/Старый дизайн/` лежат прошлые игры оператора: 4 темы
(«Временные эпохи», «Классические игры», «По жанрам музыки»,
«Тематические игры»), 67 презентаций по 0,6–1,2 ГБ, всего 55 ГБ, и 4
файла-свода (`*СВОД*.xlsx`).

В старых играх 2444 разные песни, из них **1622 нет в банке песен с
видео** (`Банк песен.xlsx`, 1071 песня). Цель — **разнообразие**:
каждый третий бочонок новой игры берётся из старых игр.

Сжимать звук, картинки и видео **не нужно** (решение оператора). Вес
презентации останется около 1 ГБ: старый слайд со звуком весит в среднем
10,3 МБ, новый видеослайд — 11,4 МБ.

## 2. Что известно о старых играх

- В старой игре 80 бочонков (в новой — 90). В своде лист — это тема,
  обычно три игры по 80 песен подряд (номера 1–80 трижды); колонки:
  номер, «Исполнитель - Название», исполнитель, название.
- Песенный слайд старой игры: фото исполнителя (иногда плюс картинка
  оформления), текст с номером, названием и исполнителем, **звук** (5449
  слайдов со звуком, 163 — с видео, видео не используем).
- **Звуковой файл на слайде целый (около 3,5 мин); 30-секундный фрагмент
  задан настройками слайда** — начало и конец обрезки (99% слайдов),
  плавное появление/затухание и громкость. Звук включается сам при
  открытии слайда.
- Тексты на слайдах записаны по-разному (порядок, регистр, перенос имени
  на две строки, опечатки). Сверка текста слайда со сводами узнаёт 97%
  слайдов (5294 из 5449); остальное — опечатки на слайдах («РОЗОВЫЙ
  ФЛАМИГО») или песни, которых нет в своде.
- Своды и папки совпадают не полностью (в своде «23 февраля» — папки нет;
  «Усатая» в своде ≈ папка «Бородатая»). Опираемся на сами слайды, своды —
  для правильного написания.

## 3. Решения

### 3.1. Банк старых слайдов — по одному файлу на песню

`Исходники/Банк старых слайдов/Исполнитель - Название.pptx` — та же
механика, что у видео (`Банк всех слайдов23.01.2026/`):

- в файле один старый песенный слайд **целиком, как был**: фото, звук с
  обрезкой, затуханием и громкостью, настройки автозапуска;
- нарезка — без PowerPoint: копия старой презентации, в которой оставлен
  один нужный слайд и только его файлы (звук, картинки, макет);
- служебные слайды (регистрация, розыгрыши, правила, «Бинго», «Удача»,
  оплата) и слайды с видео не берутся;
- если песня есть в нескольких старых играх, в банк идёт один слайд
  (предпочтение: узнан по своду однозначно, обрезка задана); остальные
  записываются в каталог как запасные;
- имя файла — написание из свода; если песня не узнана по своду — имя
  собирается из текста слайда, и песня помечается «проверить»;
- символы, недопустимые в именах файлов Windows, заменяются.

### 3.2. Общий банк песен

`Исходники/Общий банк песен.xlsx` — все песни один раз:

| Колонка | Смысл |
|---|---|
| Исполнитель - Название | как в имени файла слайда |
| Видео (караоке) | да/нет — есть файл в `Банк всех слайдов23.01.2026/` |
| Старый слайд (фото + звук) | да/нет — есть файл в `Банк старых слайдов/` |
| Откуда старый слайд | тема / игра / номер слайда в исходной презентации |
| Проверить | причина, если песня узнана неуверенно |

Отдельный лист «Проверить» — для ручной правки написания. Для программ
рядом лежит тот же список в JSON. Банк пересобирается одной командой
(например, когда оператор добавит старые игры).

**Дубли остаются:** песня может быть и с видео, и старым слайдом.

### 3.3. Подбор песен (скилл «подобрать песни»)

- Подбор идёт по общему банку.
- **Бочонки 3, 6, 9 … 90 (30 шт.)** — песни со старым слайдом;
  остальные 60 — песни с видео.
- **Песня есть в обоих видах — решает популярность:** популярную (её и
  так знают наизусть) ставим старым слайдом на бочонок, кратный трём;
  малоизвестную лучше давать с видео-караоке. Для остальных — без
  разницы.
- Все прежние правила действуют: ровно 90, без повторов, не больше 3
  песен одного исполнителя, обязательны песни по желанию и не меньше 5
  суперхитов. Песня по желанию, которая есть только старым слайдом,
  встаёт на бочонок, кратный трём; только с видео — на остальные.
- В Excel-списке новая колонка **«Вид»**: «видео» / «старый слайд».
- В `selected_songs.json` у каждого бочонка поле `kind`: `"video"` или
  `"old"`.

### 3.4. Сборка презентации

- Шаблон по умолчанию — **`Рабочий 2 вар.pptx`**: в нём каждый третий
  слот (бочонки 3, 6 … 90) — на макете «Игровой слайд». `Рабочий 3
  вар.pptx` остаётся для игр только с видео.
- Бочонки с видео — как сейчас: фигуры видеослайда накладываются поверх
  слота (`ppt_paste.py`).
- **Бочонки со старым слайдом — заполнение слота шаблона:**
  - фото исполнителя со старого слайда — в рамку «Рисунок 1» шаблона, с
    обрезкой по рамке без искажений;
  - название (заглавными) и исполнитель — в заготовки шаблона вместо
    «НА 1 СТРОЧКУ» / «ТЕКСТ НА 2 СТРОЧКИ» и «Quest Pistols Show»;
  - звук — переносится вместе с обрезкой, затуханием и громкостью,
    **включается сам** при открытии слайда, значок динамика на показе не
    виден и не лежит в правом нижнем углу;
  - номер бочонка — фигура шаблона «Текст 9».
- **Кнопка перехода на слайд 15 «Таблица»** на этих слотах уже есть в
  макете «Игровой слайд» — на слайд её не добавляем. Рамка фото
  (46–914 × 34–506 pt) частично перекрывает кнопку макета (863–960 ×
  443–540 pt); угол слайда (правая и нижняя полосы кнопки) должен
  оставаться свободным — это проверяется.
- Перед сборкой проверяется: на бочонках, кратных трём, — `kind: "old"`
  и файл есть в банке старых слайдов; на остальных — `kind: "video"` и
  файл есть в банке видео. Иначе сборка не начинается, ошибка понятным
  текстом.
- Бланки — без изменений (им всё равно, откуда песня).

### 3.5. Панель мероприятий

Поиск «песен по желанию» — по общему банку (около 3000 песен); песни,
которые есть только старым слайдом, подписаны «(старый слайд)».

## 4. Порядок работы

Каждый шаг — отдельная задача плана, после неё остановка и показ
результата оператору:

1. **Банк старых слайдов** — сначала 2–3 песни, оператор проверяет в
   PowerPoint, что звучит тот же фрагмент; затем нарезка всех.
   Результат: папка и отчёт в Excel (сколько нарезано, что проверить).
2. **Общий банк песен** — `Общий банк песен.xlsx` + JSON.
3. **Заполнение слота старой песней** — пробный слайд, оператор
   проверяет показ.
4. **Сборка всей игры на «Рабочий 2 вар»** — смесь видео и старых
   слайдов, проверка видов. Пробная игра.
5. **Скилл подбора и панель** — новые правила подбора, поиск по общему
   банку.

## 5. Проверки

- Быстрые: узнавание песни по тексту слайда и своду; выбор слайда из
  дублей; правила подбора (бочонки, кратные трём, — старые; песни по
  желанию на свои места); проверка видов перед сборкой.
- С PowerPoint: нарезанный слайд открывается, в нём один слайд, звук на
  месте с той же обрезкой; в собранном слоте фото в рамке, текст вписан,
  звук с автозапуском, угол слайда с кнопкой ничем не закрыт.
- На каждом шаге — картинки нескольких слайдов.

## 6. Что не входит

- Сжатие звука, картинок и видео.
- Переделка старых слайдов с видео (их 163 — не используются).
- Удаление папки `Старый дизайн/` — она остаётся как первоисточник;
  удалять или нет, решает оператор отдельно.

## 7. Риски

- 3% слайдов узнаются неуверенно — попадают в лист «Проверить», в подбор
  идут только после правки или как есть с пометкой.
- Около 200 слайдов подходят под несколько песен свода — выбирается
  самое длинное совпадение, такие тоже помечаются.
- Автозапуск звука хранится в настройках слайда, а не в самом звуке —
  при переносе в шаблон его нужно выставить заново; проверяется на шаге 3.
- Презентация около 1 ГБ — впритык к лимиту одного файла на бесплатном
  Яндекс Диске (1 ГБ); программа загрузки предупредит заранее.
- Банк старых слайдов займёт около 25 ГБ (на диске C свободно 336 ГБ).
